# Playwright from Zero

Code for the **Playwright from Zero** video series, for testers who are new to code. It uses Playwright 1.65 with TypeScript, and tests the public practice site https://practicesoftwaretesting.com.

Every chapter has its own folder under `chapters/` and runs on its own. Pick a chapter, `cd` into it, and follow its README.

## Requirements

[Node.js](https://nodejs.org) LTS, and [VS Code](https://code.visualstudio.com) with the Playwright Test extension.
