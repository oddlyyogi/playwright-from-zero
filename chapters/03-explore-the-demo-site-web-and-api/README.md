# Chapter 3: Explore the Demo Site: Web and API

Was the soup cold because of the waiter, or the kitchen? A restaurant hatch explains how a web page talks to its API. We start a fresh Playwright project, walk through a real demo shop, write a test map by risk, watch the hidden API calls behind a search, read the Swagger documents and JSON, write API tests with no browser, test an unknown product, create a cart, and check a web page's price against the server.

## Run it

```bash
npm install
npx playwright install
npx playwright test
```

The tests use the public practice site at https://practicesoftwaretesting.com, so they need an internet connection.
